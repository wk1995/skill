# 邮箱管理

语言： [English](README.md) | **中文**

通过现有 CLI/MCP 后端管理选定的 QQ、网易、Gmail、飞书及标准 IMAP/SMTP 邮箱，提供仅存本机的账号引用、阅读、搜索、草稿、经授权的发送和基础管理。用于邮箱接入和邮件任务，不用于邮件服务器运维或营销群发。

## 如何使用

明确账号和任务，例如：

- “接入我的 QQ 测试邮箱，先验证只读访问。”
- “搜索选定网易账号最近七天来自供应商的未读邮件。”
- “在 Gmail 原线程保存回复草稿，发送前先给我看内容。”
- “把选定附件下载到我的本机私有目录。”
- “只搜索这两个账号，每条结果保留邮箱来源。”

需要已有可用后端及相应账号权限。本 Skill 负责选择和操作工具，不替代邮件客户端，也不自带已授权连接。缺少工具或资格时会说明具体缺项，不静默安装、换账号或发送测试邮件。

附带的[本机账号工具](references/local-storage.md)可以验证本地路径、保存非秘密账号引用、跨会话列出/选择账号及删除所选引用。需要 Python 3.10+ 和 POSIX 私有文件权限；Windows 写入在提供并验证 ACL 适配前明确不可用。工具不连接邮箱、不保存密码/token、不执行邮件后端。移除账号引用不删除凭据、邮件或附件。

## 何时触发

邮箱接入或选择；阅读、搜索和分析选定邮箱；邮件撰写及云端草稿；明确授权的发送、回复、转发；选定附件下载和基础邮件管理。

## 何时不触发

邮件服务器或全租户管理、DNS/SPF/DKIM/DMARC、营销/批量群发、永久删除、无邮件意图的普通写作，以及无关的联系人、日历、聊天、文档操作。用户显式选择专用 Skill 时保持其流程，不重复执行写操作。

## 真实信息只存本机

**全部真实邮箱信息**放在 Git 和 Skill 安装目录之外，包括地址、别名、原生配置、凭据、邮件内容、附件、日志、测试证据与备份。默认账号索引使用本机 XDG 配置目录，状态/缓存/持久数据分离。只分发虚构定义和公开服务说明。已实现检查与平台限制见[本地存储](references/local-storage.md)。
