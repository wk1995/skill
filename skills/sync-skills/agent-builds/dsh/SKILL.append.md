## DeepSeek Harness Sync Adaptation

For a DeepSeek Harness `local` role, resolve the Skill directory from the installed Harness user root (`$DSH_HOME/skills`, default `~/.dsh/skills`) or the shared `~/.agents/skills` root. Synchronize the materialized DeepSeek Harness build, and do not copy Codex-only metadata or another Agent's artifact.
